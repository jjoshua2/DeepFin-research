# DeepFin research

Living, searchable experiment records for [DeepFin](https://github.com/jjoshua2/DeepFin). New research prose belongs here, with preregistration, subsequent readouts, negative results and source-qualified artifact identities kept together.

- [Record index](docs/experiments/README.md)
- [Original source manifest](provenance/source-manifest.tsv)
- [Import and migration provenance](provenance/import.json)
- [Rights and attribution](RIGHTS.md)

This initial import contains 251 already-public Markdown records, including 41 scratchpad records. Original bytes are preserved in import commit 8536ec99471478efee257e9b7bbeb4d3e614854b. Presentation edits only add attribution and link retained evidence/current-source context to the exact original DeepFin revision. Code blocks, local paths and historical instructions remain evidence, not current operating authority.

Earlier history remains searchable in the original DeepFin repository. This repository begins new history at the recorded import; no source history was rewritten. Main retains 130 imported source copies with evidence, provenance or runtime bindings, plus all Bend/proofs, verifiers and machine-read evidence.

Large datasets, labels, weights, checkpoints and bulk logs stay in existing artifact storage. Record their source identities, hashes and restore locations here. Do not copy live or private receipts into this public repository.

Research prose changes receive review here; changes affecting executable consumers or qualification evidence require the relevant code/evidence review. DeepFin pins an explicit research commit as an optional submodule, so ordinary production code reviews do not include every record body.

Search the initialized checkout with rg; search earlier history in DeepFin at the source commit from provenance/source.json. Follow-ups should link original records and preserve their failed/inconclusive verdicts rather than rewriting conclusions.
